# 03. Ubuntu Linux

## 1. Overview & Philosophy
- **Governance:** Developed by Canonical and built on [Debian](https://labex.io/lesson/debian), inheriting its robust `.deb` package format, `apt` package manager, and core tooling while providing its own release schedule, defaults, and support model.
- **Accessibility:** Known for its polished installer, predictable releases, and large user community, making it one of the most widely used Linux distributions across desktops, virtual machines, servers, and cloud platforms.

## 2. Release Cycle
Ubuntu maintains two primary release types to balance cutting-edge features with production stability:
- **Interim Releases:** Published every **6 months**, delivering newer software packages and features for users who want rapid updates.
- **Long Term Support (LTS) Releases:** Published every **2 years**, providing a stable, long-lived foundation preferred for workstations and production servers.

## 3. Package Management
- Uses the **`.deb`** package format and the **`apt`** package manager for installing, updating, and removing software.
- Combines mature Debian tooling with a massive, well-documented software ecosystem and community-driven tutorials.

## 4. Desktop and Server Use
- **Desktop:** Features a polished GNOME-based interface with approachable defaults.
- **Server:** Extensively deployed in development environments, web infrastructure, and enterprise cloud platforms.
