# AWS Cloud, Data Engineering & AI Infrastructure (32-Week Curriculum)

A structured, hands-on engineering portfolio documenting an 8-month progression through Linux systems administration, cloud networking, data engineering infrastructure, DevOps/IaC, and production MLOps.

## Curriculum Architecture

| Module | Weeks | Focus Areas |
| :--- | :--- | :--- |
| **01. Linux & Networking** | Weeks 01–04 | Filesystem hierarchy, permissions, systemd, Bash scripting, TCP/IP, DNS, firewalls, SSH hardening |
| **02. AWS Cloud Engineering** | Weeks 05–12 | IAM, VPC networking, EC2, S3, RDS, serverless architectures, high availability & cost optimization |
| **03. Data Engineering Infrastructure** | Weeks 13–17 | Distributed storage, data lakes, ETL/ELT orchestration, streaming pipelines, warehouse infrastructure |
| **04. DevOps & Platform Engineering** | Weeks 18–23 | Docker, Kubernetes, Terraform (IaC), CI/CD pipelines (GitHub Actions), observability & monitoring |
| **05. MLOps & AI Infrastructure** | Weeks 24–28 | Model serving, GPU/compute orchestration, vector databases, RAG pipelines, automated model registries |
| **06. Production & Capstone** | Weeks 29–32 | End-to-end multi-service production architecture, security auditing, load testing, capstone deployment |

## Repository Conventions
- **Zero-Secret Policy:** All credentials, `.env` files, keys, and Terraform state files are strictly excluded via `.gitignore`.
- **Reproducible Labs:** Every weekly module contains structured `notes/`, `labs/`, `assignments/`, `scripts/`, `screenshots/`, and `assessment/` artifacts.
